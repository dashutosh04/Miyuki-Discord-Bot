# ✨ Miyuki's Documentation

## 🚧 Miyuki's Info

- Miyuki is a multipurpose bot.
- It includes features such as music, moderation, etc.
- Universal Prefix is `miyu`
- Help command can be viewed by `miyu help` or `{changed_prefix} help`
